# Merge Garden - Game Pitch

## Game Overview

**Merge Garden** is a casual puzzle merge game combining satisfying merge mechanics with strategic progression. Players tap cells to spawn seeds, merge identical plants to evolve them, and upgrade their garden to unlock rare items and higher rewards.

**Target Platform:** Web, iOS, Android (via framework conversion)
**Target Audience:** Casual players aged 13+, merge game enthusiasts
**Core Loop:** Spawn → Merge → Upgrade → Level Up

---

## Game Features

### Core Mechanics
- 5x5 grid board
- Merge system with adjacent matching items
- Progressive evolution through 9 tiers of item complexity
- Combo system for higher reward multipliers
- Board compaction after merge cycles

### Progression System
- Score-based progression with level targets
- Goal-based advancement across stages
- Increasing rewards as player grows garden

### Monetization Features
- Produce button and boost economy
- Daily reward loop
- Shop upgrades for water, soil, and luck
- Rewarded ad potential for bonus rewards
- IAP support for boosts and premium content

### Engagement Features
- Combo badge and feedback messaging
- Dynamic score and coin updates
- Audio feedback and animation polish
- Simple accessible gameplay loop

---

## Game Loop Flow

1. Spawn a seed into an empty cell
2. Merge matching items to evolve them
3. Earn coins and score
4. Buy upgrades in the shop
5. Reach level goals
6. Repeat with stronger progression and faster rewards
