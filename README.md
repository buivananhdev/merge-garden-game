# Merge Garden

A polished casual merge game prototype built with HTML5 / JavaScript. Players spawn crops, merge matching items, earn coins, upgrade their garden, and climb through increasing levels.

## Gameplay

- 5x5 merge board
- Tap empty cells to spawn new crops
- Merge matching crops to evolve them into larger, more valuable items
- Earn coins and score from successful merges
- Unlock upgrades for water, soil, and luck
- Use daily rewards and boosts to keep progression fluid
- Progress through levels by meeting score goals

## Features

- Casual merge gameplay loop
- Score, level, and progression tracking
- Coin economy with upgrade system
- Daily reward system
- Boost mechanic for faster progression
- Mobile-friendly layout
- Light audio feedback for actions

## How to Run

Open `index.html` in any modern web browser.

If you want to run it locally via a simple web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
